# tg-cases: кейсы из переписки в Telegram

Скрипт находит в выгрузке Telegram чаты, похожие на фриланс-заказы.
Расшифровывает голосовые и видеосообщения прямо на твоём Mac.
По каждому заказу собирает досье, из которого Claude делает черновик кейса для портфолио.

## Приватность

- Всё работает на твоём компьютере. Сам скрипт ничего не отправляет в интернет.
- Интернет нужен только для установки: uv и сам скрипт скачиваются из интернета, uv при первом запуске ставит Python и библиотеки, а библиотека распознавания один раз скачивает модель с Hugging Face (около 1,6 ГБ). Переписка при этом никуда не уходит.
- Результат лежит в папке `~/tg-cases`. Там переписка с клиентами: не коммить её в git, не клади в облако и не пересылай. Скрипт скрывает в досье телефоны, почты, адреса, карты, реквизиты, пароли и ключи, но имена и суть разговоров остаются. Скрытие работает по шаблонам и может что-то пропустить: перед тем как отдать досье, пролистай его.
- Claude работает только в папке `~/tg-cases/claude`: там досье, инструкция `CLAUDE.md` и черновики кейсов. Отчёт со всеми чатами и кэш расшифровок лежат уровнем выше, и настройки в этой папке запрещают Claude Code их читать.
- Когда кейсы готовы, удали выгрузку Telegram и папку `~/tg-cases` (шаг 6).

## Шаг 0. Поставь uv

uv запускает скрипт и сам ставит всё, что ему нужно.

1. Открой Терминал: Cmd+Пробел, набери «Терминал», Enter.
2. Вставь команду и нажми Enter:

   ```
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

3. Чтобы uv заработал в этом же окне, выполни:

   ```
   source $HOME/.local/bin/env
   ```

   Или просто открой новое окно Терминала.
4. Проверь: `uv --version` печатает номер версии.

Если у тебя есть Homebrew, можно так: `brew install uv`.

## Шаг 1. Выгрузи переписку из Telegram Desktop

Нужен Telegram Desktop с сайта [desktop.telegram.org](https://desktop.telegram.org). Обычное приложение Telegram из App Store выгружать переписку не умеет.

Оба приложения называются «Telegram». Когда переносишь Telegram Desktop в «Программы», Finder спросит про замену: нажми «Оставить оба». Telegram Desktop появится как «Telegram 2». Отличить просто: только в Telegram Desktop в настройках есть «Продвинутые настройки». Войди в него по QR-коду с телефона.

1. В Telegram Desktop открой «Настройки», затем «Продвинутые настройки». В самом низу нажми «Экспорт данных из Telegram».
2. Отметь так:
   - «Информация об аккаунте»: оставь. По ней скрипт понимает, какие сообщения твои.
   - «Список контактов» и остальное в первом блоке: сними.
   - «Личные чаты»: отметь.
   - «Частные группы»: отметь и сними «Только мои сообщения». Иначе в выгрузке не будет сообщений заказчиков.
   - «Чаты с ботами», «Частные каналы», «Публичные группы», «Публичные каналы»: сними. Выгрузка будет меньше и быстрее.
   - Вложения: отметь только «Голосовые сообщения» и «Видеосообщения». «Фотографии» включены по умолчанию, сними.
   - «Ограничение по размеру»: сдвинь вправо, до 500 МБ или больше. Иначе длинные видеосообщения не попадут в выгрузку.
   - «Активные сеансы» и «Другие данные»: сними.
   - Формат: «Машиночитаемый JSON». По умолчанию стоит HTML, его скрипт не читает.
3. Нажми «Экспортировать». Если Telegram просит подождать до 24 часов, это защита аккаунта: вернись позже на этом же компьютере и повтори.
4. Голосовые всех чатов могут занять несколько гигабайт, а выгрузка идти час и дольше. Когда она закончится, кнопка «Просмотр» откроет папку. Обычно это «Загрузки», папка «Telegram Desktop», внутри папка вида `DataExport_2026-10-11`.

Названия пунктов в твоей версии Telegram могут чуть отличаться.

Если места мало, выгружай в два захода. Сначала всё по списку выше, но без вложений: это быстро. Найди заказчиков (шаг 3). Потом выгрузи только их чаты с голосовыми, как написано ниже. Telegram сложит эти выгрузки в ту же папку «Telegram Desktop». Запусти шаг 3 ещё раз и перетащи в Терминал саму папку «Telegram Desktop»: скрипт возьмёт копии чатов с голосовыми.

Отдельный чат выгружается так: в чате открой меню (три точки справа вверху), «Экспорт истории чата». В окне экспорта отметь «Голосовые сообщения» и «Видеосообщения», сними «Фотографии», сдвинь ограничение по размеру вправо, формат «Машиночитаемый JSON».

Когда выгрузка готова, выйди из Telegram Desktop: «Настройки», меню с тремя точками, «Выйти». Или заверши этот сеанс на телефоне: «Настройки», «Устройства».

## Шаг 2. Скачай скрипт

Вставь в Терминал:

```
mkdir -p ~/tg-cases-tool && curl -fsSL -o ~/tg-cases-tool/tg_cases.py https://raw.githubusercontent.com/imevstratov-pixel/portfolio/refs/heads/claude/gallant-ptolemy-ar6ccv/tools/tg-cases/tg_cases.py
```

Или скачай файл `tg_cases.py` из чата с Claude и положи его в папку `tg-cases-tool` в своей домашней папке.

## Шаг 3. Найди чаты с заказами

1. Набери в Терминале, в конце поставь пробел, Enter пока не нажимай:

   ```
   uv run ~/tg-cases-tool/tg_cases.py find 
   ```

2. Перетащи папку выгрузки из Finder в окно Терминала: путь вставится сам.
3. Нажми Enter.
4. Если macOS спросит, можно ли Терминалу открыть папку «Загрузки», нажми «Разрешить».

Первый запуск займёт пару минут: uv ставит Python и библиотеки, это 150-300 МБ. Потом в браузере откроется отчёт `~/tg-cases/candidates.html`, а в Терминале появится короткая сводка.

Полезные добавки к команде:

- `--since 2022-01-01`: учитывать только сообщения с этой даты. Пометка NDA всё равно считается по всей переписке.
- `--nda 'Skillbox, Скиллбокс'`: ещё слова, по которым чат помечается как NDA. Tixu и Eduson помечаются всегда. Скопированная из отчёта команда передаст эти слова дальше.
- `--me 'Даниил Евстратов'`: если скрипт ошибся и решил, что ты кто-то другой.

## Шаг 4. Отметь заказчиков и собери досье

1. В отчёте отметь галочками чаты заказчиков. «Подробнее» показывает начало переписки, ключевые слова и суммы. Поиск находит чат по имени и фамилии собеседника.
2. Раздел «Почти без текста» показывает чаты, где о работе почти не писали, но много голосовых и звонков. Загляни в них: о заказе могли договариваться голосом.
3. Чаты с пометкой NDA не отмечены. Отмечай их, только если это фриланс, а не работа в компании.
4. Нажми «Скопировать команду» внизу, вставь в Терминал, нажми Enter.

Скрипт расшифрует голосовые и видеосообщения и сложит досье в `~/tg-cases/claude/dossiers`.

Сколько ждать:

- Первый запуск скачивает модель распознавания, около 1,6 ГБ. Это один раз.
- Mac с M1 и новее: минута голосовых расшифровывается за 5-12 секунд.
- Mac с Intel: минута голосовых за 20-30 секунд.

Прервать можно Ctrl+C. Чтобы продолжить, нажми в Терминале стрелку вверх и Enter: скрипт начнёт с того же места.

## Шаг 5. Черновики кейсов с Claude

Вариант 1, Claude Code. В Терминале:

```
cd ~/tg-cases/claude
claude
```

Напиши: `Прочитай CLAUDE.md и сделай черновики кейсов по всем досье`. Claude сложит кейсы в `~/tg-cases/claude/cases` и составит `00-обзор.md`: какие кейсы публиковать первыми и почему.

Вариант 2, claude.ai. Создай чат, прикрепи `~/tg-cases/claude/CLAUDE.md` и одно досье из `~/tg-cases/claude/dossiers`. Если досье разбито на части (`.part1`, `.part2`), прикрепи все части. Напиши: `Сделай кейс по инструкции`. Папку в Finder открывает команда `open ~/tg-cases/claude`.

Вариант 3, чат с Claude, где ты собираешь портфолио. Прикрепи `CLAUDE.md` и досье и попроси прислать только текст кейса. Этот чат работает с публичным репозиторием сайта, поэтому попроси не сохранять досье в репозиторий.

Отчёт `candidates.html` и папку `~/tg-cases/.cache` Claude не показывай: там переписка со всеми, в том числе чаты под NDA.

## Шаг 6. Согласие заказчика и уборка

В каждом кейсе есть раздел «Сообщение заказчику»: готовый текст, чтобы спросить разрешение на публикацию и попросить отзыв. Пока заказчик не ответил, публикуй только анонимный вариант: без названия компании и имён.

Когда всё готово:

1. Перенеси нужные кейсы из `~/tg-cases/claude/cases` туда, где будешь их хранить.
2. Удали рабочие папки и кэш uv:

   ```
   rm -rf ~/tg-cases ~/tg-cases-tool
   uv cache clean
   ```

3. Удали выгрузку Telegram из «Загрузок» и очисти Корзину.
4. Модель распознавания лежит в `~/.cache/huggingface`, её тоже можно удалить.

## Если что-то пошло не так

**`command not found: uv`.** Терминал ещё не видит uv. Выполни `source $HOME/.local/bin/env` или открой новое окно. Не помогло: пиши `~/.local/bin/uv` вместо `uv`.

**curl пишет `404`.** Ссылка на скрипт устарела. Скачай `tg_cases.py` из чата с Claude и положи в `~/tg-cases-tool`.

**«macOS не даёт Терминалу открыть эту папку».** Открой «Системные настройки», «Конфиденциальность и безопасность», «Файлы и папки» и включи для Терминала доступ к «Загрузкам». Или перенеси папку выгрузки в домашнюю папку.

**«Ошибка в команде: лишние параметры».** В пути к папке есть пробел. Вставь путь перетаскиванием папки из Finder или возьми его в одинарные кавычки.

**«Похоже, чаты выгружены в формате HTML».** Повтори шаг 1 и выбери «Машиночитаемый JSON».

**В досье «(голосовое не выгружено)».** При экспорте не были отмечены «Голосовые сообщения» или «Видеосообщения», или файл больше ограничения по размеру. Выгрузи этот чат ещё раз через «Экспорт истории чата» с голосовыми (шаг 1). Запусти шаг 3 на папку «Telegram Desktop», где лежат обе выгрузки, и скопируй команду из отчёта заново. Готовые расшифровки не пропадут.

**Ошибка про библиотеки распознавания.** Запускай через `uv run`, а не через `python3`. Собрать досье без расшифровки: добавь в конец команды `--no-voice`.

**Ошибка загрузки модели.** Проверь интернет и свободное место (нужно около 3 ГБ) и запусти команду ещё раз.

**Медленно на Mac с Intel.** Это нормально: распознавание идёт на процессоре. Оставь компьютер работать или добавь `--no-voice`.

**Скрипт пишет про Rosetta.** Терминал запущен в режиме Intel, хотя Mac на M1 и новее. Проверь: `uname -m` должен печатать `arm64`. Исправить так:

1. Закрой Терминал. В Finder открой «Программы», «Утилиты», нажми на «Терминал» правой кнопкой, «Свойства».
2. Сними «Открывать в режиме Rosetta» и снова открой Терминал.
3. Выполни `rm ~/.local/bin/uv` и повтори шаг 0.
4. Если `which uv` печатает `/usr/local/bin/uv`, это uv из Homebrew для Intel. Удали его командой `/usr/local/bin/brew uninstall uv` и повтори шаг 0.

**В расшифровке не тот язык.** Добавь к команде `--lang ru` и запусти ещё раз: голосовые этого чата расшифруются заново.

**Закончилось место на диске.** Модели нужно 1,6 ГБ в `~/.cache/huggingface`. Освободи место и запусти снова: скрипт продолжит.

**Хочу пересобрать один чат.** Запусти build только с его номером: `--chats 123456`. Досье перезапишется под тем же номером. Номер чата есть в отчёте после «id». Чтобы заново расшифровать голосовые, удали `~/tg-cases/.cache/transcripts.json`.

**Нужного чата нет в отчёте.** Каналы, боты, публичные группы и «Избранное» скрипт пропускает. Проверь, что чат попал в выгрузку: личные чаты и частные группы должны быть отмечены в шаге 1.

**Скрипт решил, что ты это кто-то другой.** Добавь `--me 'Имя Фамилия'`, как имя записано в Telegram.
